# 📚 Library Management System

A simple web-based **Library Management System** built using **HTML**, **Tailwind CSS**, and **JavaScript**. The application allows users to register, log in, and manage books efficiently through an easy-to-use interface.

---

## 🚀 Features

- User Registration
- User Login and Logout
- Add New Books
- Edit Book Information
- Delete Books
- Search Books by Title, Author, or Category
- Borrow and Return Books
- Library Statistics Dashboard
- Search Books Online using the Open Library API
- Responsive User Interface

---

## 🛠 Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (ES6)
- Local Storage (User Authentication)
- Open Library API

## 📖 How to Use

### 1. Register

- Open **register.html**
- Create a new account using a username and password.

### 2. Login

- Open **login.html**
- Enter your registered username and password.
- You will be redirected to the Library Management System.

### 3. Manage Books

You can:

- Add new books
- Edit existing books
- Delete books
- Borrow or return books
- Search books by title, author, or category

### 4. Search Books Online

- Enter a book title in the **Search a Book Online** field.
- Click **Search**.
- The system automatically fills the book title, author, and category using the Open Library API.

---

## 📚 Open Library API

This project uses the Open Library Search API.

Example:

https://openlibrary.org/search.json?title=Harry%20Potter

The API is used to automatically retrieve:

- Book Title
- Author
- Category (when available)
